## Yeniden üretmek

```
npm run build && npx next start -p 3100                                  # çekim sitenin yazı tiplerini ve dokularını kullanır
FILM_EPOCH="2026-10-09T21:00:00+03:00" npm run film -- v gece            # GPU'suz Linux'ta FILM_GL=swiftshader ekleyin
SNAP="3,8,15" npm run film -- v gece                                     # video yerine kontrol kareleri (video/_kontrol/gece)
```

Başka bir gün için yalnızca `tools/film/gece/veri.json` dosyasını güncelle. Tarih, gün, Ay, gezegen saatleri ve
geri sayımlar sahnelere oradan gelir.
